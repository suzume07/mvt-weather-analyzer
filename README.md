# mvt-weather-analyzer
Dự báo thời tiết và đánh giá việc làm tròn trong thống kê với kết quả dự đoán đầu ra
Mục tiêu: tái dùng ý tưởng MVT-analyzer (tìm điểm slope trung bình) cho dữ liệu thời tiết, đồng thời khảo sát ảnh hưởng của việc làm tròn dữ liệu lên độ chính xác dự đoán.
