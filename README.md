# mvt-weather-analyzer
Dự báo thời tiết và đánh giá việc làm tròn trong thống kê với kết quả dự đoán đầu ra
Mục tiêu: tái dùng ý tưởng MVT-analyzer (tìm điểm slope trung bình) cho dữ liệu thời tiết, đồng thời khảo sát ảnh hưởng của việc làm tròn dữ liệu lên độ chính xác dự đoán.

# 🌤 Weather MVT Analyzer

Ứng dụng phân tích dữ liệu thời tiết bằng Định lý Giá trị Trung bình (MVT).

## 🚀 Tính năng chính
- Tải hoặc nhập dữ liệu thời tiết (CSV)
- Vẽ biểu đồ các yếu tố thời tiết theo thời gian
- Tính tốc độ thay đổi trung bình, đạo hàm xấp xỉ
- Ước lượng điểm MVT trên mỗi khoảng
- Giải thích ảnh hưởng của việc làm tròn dữ liệu
